# Empire Cigars Brand Kit
Open `guidelines/brand-guidelines.md` first.

Contents:
- `logos/` — primary logo, wordmark, monogram in SVG and PNG where available
- `favicons/` — favicon.ico, PNG favicons, app icon sizes
- `social/` — profile avatar sizes and social cover image
- `packaging/` — cigar band concept template
- `web/` — CSS variables and JSON design tokens
- `guidelines/` — brand guide

Important: logo and packaging assets are concept masters, not a substitute for final print-production artwork. Verify all trademark and regulatory requirements before launch.
